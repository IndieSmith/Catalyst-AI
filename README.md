# Catalyst-AI
Catalyst AI is an AI assistant project developed by Harsh (Panda) and Anu (Anurag).

The goal of Catalyst AI is to build a powerful, modern, and independent AI assistant with a clean interface and expandable capabilities.

## Features
- Modern AI chat interface
- Animated message sending and responses
- Conversation-based interactions
- Powered by an AI language model
- Custom system behavior and personality
- Expandable architecture
- Planned internet connectivity
- Future support for additional tools and capabilities

## Tech Stack
- HTML
- CSS
- JavaScript
- Python
- AI / LLM APIs and models

## Project Status

🚧 Currently under active development

Catalyst AI is currently being developed step by step. The project currently includes a custom chat interface and AI model integration.

## Current Development
- Create Catalyst AI interface
- Build chat functionality
- Connect an AI model
- Customize AI behavior
- Improve UI animations
- Connect Catalyst AI to the internet
- Add web search capabilities
- Add memory system
- Add voice capabilities
- Improve reasoning and tool usage

## Vision
  The long-term vision of Catalyst AI is to create a capable AI assistant that can understand users, access useful information, use tools, and continuously expand with new capabilities.
